# Diario de Erros — TCDF/ANACE

> Preencha depois de cada lote de questoes. Um erro que nao vira linha aqui volta na prova.

## Como usar

1. Registre **todo** erro e todo acerto com duvida.
2. Classifique a causa — e a causa que decide para qual agente o erro volta.
3. Marque a data de retorno: 24-48h para erro critico, 7 dias para instavel.
4. Leve a tabela para o `mentor-desempenho` no fim da semana.
